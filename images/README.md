# Images

실제 목업, 프로젝트 이미지, 영상 포스터를 이 폴더에 저장합니다.

- 영문 소문자와 하이픈으로 파일명을 작성합니다. 예: `nintendo-cover.webp`
- 원본 비율과 색상을 유지합니다.
- 목업 템플릿의 출처와 사용 권한은 `CONTENT.md`에 기록합니다.
- Nintendo 표지 목업은 사용자가 지정한 팀 프로젝트 Figma의 `01_Hero` 노드(1148:6400)를 화면 미리보기로 사용합니다. `nintendo-hero.png`는 해당 노드에서 내보낸 이미지이며, 배포 사이트의 실제 캡처라고 간주하지 않습니다.
- 클론 코딩 섹션은 사용자가 지정한 포트폴리오 Figma 70:17 프레임의 에셋을 로컬 파일로 사용합니다: `clone-runner.png`, `clone-product.png`, `clone-monogram.png`, `clone-rule-*.svg`.
- 그 외 Persona 레퍼런스 이미지는 레이아웃 참고용이며 실제 작업 결과물로 사용하지 않습니다.
